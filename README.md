# TikTok通知采集 V1.0.1（V1.0 安全加固版）

Chrome Manifest V3 扩展（需要 Chrome 102 或更新版本）+ Google Apps Script 接收端。只在已打开的 `https://www.tiktok.com/` 页面读取通知（评论、点赞、粉丝），写入由用户配置并经接收端授权的 Google 表格。

## 保留的功能

- 自动（约每 2 小时，空闲时采集）、手动和暂停模式。
- TikTok 悬浮采集按钮，可以点击 × 隐藏，并在插件弹窗中重新显示。
- Token 密码输入与显示/隐藏、按 TikTok 账号标注、插件内时区选择（默认越南 `Asia/Ho_Chi_Minh`）。
- 目标工作表按表格链接中的 ID 和 gid 定位；新记录从**第 3 行插入**，已有记录下移，第 1、2 行保持不变。
- 评论额外写入「评论收集」，网络故障暂存待补发，插件本地去重 + Apps Script 服务端去重。

## 安装 / 升级（先备份）

1. 备份 Chrome 插件原有配置，尤其是 Apps Script 接收地址、目标表格链接和 Token；请勿把 Token 上传 GitHub。
2. 在 **Google Apps Script 原项目**中用 `AppsScript接收端_V1.0.1.gs` 的完整内容替换旧文件。
3. 打开 Apps Script 左侧**项目设置（齿轮）→ 脚本属性**，新增以下配置并保存：

   | 属性名 | 用途 | 是否必需 |
   | --- | --- | --- |
   | `TOKEN` | 与插件中输入的一致，至少 24 字符，建议使用随机生成的 32 字符以上 Token | **必需** |
   | `DEFAULT_SPREADSHEET_ID` | 插件没有指定目标表格时使用的默认表格 ID；这个表格自动允许写入 | 按需 |
   | `ALLOWED_SPREADSHEET_IDS` | 允许写入的其他表格 ID，多个 ID 使用英文逗号分隔 | 使用插件指定的其他表格时**必需** |

   **示例：** 假设你只使用 A 表格，设置 `DEFAULT_SPREADSHEET_ID` 为 A 的 ID 即可；如果还要让插件写 B/C 表格，请在 `ALLOWED_SPREADSHEET_IDS` 中增加 B、C 的 ID。请填写实际值，不要把凭据发布到公开仓库。

4. Apps Script **部署 → 管理部署 → 编辑原部署 → 选择新版本 → 部署**。使用原部署时通常能保留原 `/exec` 网址。
5. 备份 Chrome 当前加载的扩展文件夹，然后用 ZIP 内的 **`TikTok通知采集` 文件夹中的文件覆盖原有文件**，进入 `chrome://extensions`，点击**重新加载**；这样更有机会保留原扩展 ID 和旧设置。不要同时启用旧版与新版。
6. 在弹窗填写（或核对）Apps Script `/exec` URL、**新 Token**、目标表格网址（`https://docs.google.com/spreadsheets/d/.../edit#gid=...`）、账号和时区。
7. 使用测试账号先采集 1 条评论和 1 条点赞，确认第 3 行插入、评论双写和发送成功，再启用自动采集。

**升级提醒：** 这一版接收端不再读取硬编码的 `TOKEN` 和表格 ID。若未按以上说明添加脚本属性，将**拒绝写入**；这是有意设计的安全默认值。新接收端采用表格白名单，新增目标表格时需要同步登记 ID。

## 重要安全变化

- Google Sheets 以 `=` 开头的外部评论写入前转义，避免被解释为公式。
- Apps Script 按有效 Token、表格白名单、内容类型和长度验证请求；脚本错误仅返回通用消息。
- 在 Apps Script 锁内核对已有记录防止网络重试重复入库；评论汇总单独检查，可在局部失败后补写。
- 插件本地存储限制为可信扩展上下文，TikTok 内容脚本只能通过受控消息读取不含 Token 的界面设置。
- 采集任务使用一次性任务 ID 校验结果来源；页面悬浮按钮仅请求后台启动采集，不直接上传结果。
- 诊断模式只发送不含账号和评论原文的结构摘要，旧版待补发的原始 HTML 快照在发送时会被替换成脱敏说明。
- 待补发容量：最多 100 批、估算不超过 5 MiB；发送请求 25 秒超时并保留失败批次；本地已发送指纹缓存按约 3 MiB 上限清理，服务端继续去重。超额时拒绝保存新批次并明确报错，不会悄悄清除已有队列。
- 限制运行环境为 HTTPS 的 `www.tiktok.com`，不再匹配 HTTP 或其他子域。

## 尚不能承诺的事项

- **不能承诺 100% 去重：** TikTok 通知若缺少唯一 ID，两个不同事件的内容完全相同可能被合并；缺少关键字段时接收端选择不去重，以避免误删。已写入的历史重复不会自动删除。
- Google Sheets 是表格，不是事务数据库。多表写入中途失败可能出现局部成功，接收端会在重试时尝试补齐，但无法保证所有故障下都恰好一次。
- 用于防重的现有表扫描随表格数据变大而变慢；Google Apps Script 配额与执行时间限制仍有效。
- Token 仍需持久保存在本机 Chrome 扩展设置中；本机被入侵、Token 泄露或被管理员手动导出时，口令可被窃取。**旧 Token 曾公开展示或上传时必须轮换。**
- 未在真实 TikTok/Chrome/Google 表格账号中进行端到端测试；请先测试再替换生产环境。
